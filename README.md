# sql-datetime-flight-case-study
SQL case study using a flight dataset to practice date and time functions, aggregation, filtering, and analytical queries.

## 📌 Overview

This project is a SQL case study based on a flight dataset. 
The objective is to analyze flight data using SQL and practice 
date and time functions, aggregation, filtering, grouping, and 
conditional logic.

## 🎯 Objectives

- Analyze flight schedules and departure times
- Practice SQL Date & Time functions
- Categorize flights based on departure time
- Calculate average flight prices
- Analyze flight patterns by day of the week
- Use CASE statements for conditional analysis
- Practice GROUP BY, ORDER BY, WHERE, and aggregate functions

## 🛠️ SQL Concepts Used

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- CASE WHEN
- SUM()
- AVG()
- COUNT()
- HOUR()
- DAYNAME()
- DAYOFWEEK()
- Date & Time Functions
- Conditional Aggregation
